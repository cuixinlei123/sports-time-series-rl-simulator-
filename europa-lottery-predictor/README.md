# 欧罗巴赛事 · 中国体彩竞彩足球职业预测解析系统

> 基于 **Elo 实力评分 + Poisson 进球模型 + 赔率价值分析** 的竞彩足球概率预测与价值投注推荐引擎。

## 二、竞彩足球五大玩法规则（欧罗巴赛事适用）

| 玩法 | 说明 |
|------|------|
| **胜平负** | 竞猜全场主队胜/平/负，赔率即奖金倍数 |
| **让球胜平负** | 比分加上让球数后再判胜负，平衡强弱差 |
| **比分** | 竞猜全场准确比分（如 1:0、2:1），赔率高 |
| **总进球** | 竞猜全场总进球数，分 0/1/2/3/4/5/6/7+ 八档 |
| **半全场** | 同时猜半场+全场胜平负，共 9 种组合 |

## 三、数据获取与计算核心逻辑

### 1. Elo 实力评分
```
E_A = 1 / (1 + 10^((R_B - R_A)/400))
主场加成 +65 Elo；近期状态（近6场胜率）× 0.9~1.1 修正
```

### 2. Poisson 进球模型
```
λ_home = 1.35 × 进攻系数_主 × 防守系数_客 × (1 + 主场加成)
λ_away = 1.35 × 进攻系数_客 × 防守系数_主 × (1 − 主场加成×0.5)
P(i:j) = Poisson(i; λ_home) × Poisson(j; λ_away)
```
由比分矩阵聚合得到胜平负、让球胜平负、总进球分布；
半场 λ 取全场 ×0.45，独立假设下得到半全场 9 组合概率。

### 3. 赔率价值分析
```
隐含概率 = 1 / 赔率（去抽水后归一化）
EV = 模型概率 × 赔率 − 1
当 EV > 0 → 模型认为市场低估，构成价值投注
```

### 4. 概率融合
最终胜平负概率 = 0.4 × Elo 胜率 + 0.6 × Poisson 矩阵胜率（归一化）

## 五、使用方式

### 命令行工具

```bash
# 列出所有示例比赛
python run.py list

# 分析第 1 场（完整报告）
python run.py predict --index 1

# 按 ID 分析
python run.py predict --match-id UEL-2026-002

# 自定义 JSON 输入，输出 JSON 结果
python run.py predict-json --json '{"home_team":"阿森纳","away_team":"PSV",...}'
```

### 网页演示

```bash
pip install flask numpy pandas
python -m web.app
# 浏览器打开 http://127.0.0.1:5000
```

页面特性：
- 初始化即展示 3 场欧罗巴示例比赛及第一场的完整预测结果
- 点击任意比赛卡片 → 现场运行预测引擎 → 渲染概率图表与价值投注推荐
- 顶部规则解析面板说明五大玩法
